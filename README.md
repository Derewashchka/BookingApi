# BookingAPI

RESTful API для управління бронюваннями та орендою конференц-залів, розроблене на базі ASP.NET Core. 

## Опис бізнес-завдань
Компанія надає в оренду конференц-зали для бізнесу. Головна мета цього АРІ - забезпечити клієнтам можливість:
- Шукати доступні зали за датою, часом та необхідною місткістю.
- Бронювати зали з додаванням супутніх послуг (Wi-Fi, проєктор, звукове обладнання).
- Автоматично розраховувати вартість оренди завдяки динамічній системі ціноутворення (врахування ранкових, стандартних, вечірніх та пікових годин).
- Надавати бізнесу аналітичні звіти щодо загального доходу та популярності залів.

## Технічні рішення та Архітектура
Проєкт побудовано з дотриманням принципів чистого коду (SOLID) та розділенням відповідальності:
- **Платформа:** ASP.NET Core Web API (.NET 9).
- **База даних:** SQLite. Використовується через Entity Framework Core. Вибрана для простоти розгортання та тестування завдання без додаткових налаштувань сервера бази даних.
- **Архітектурний підхід:** 
  - **Controllers** відповідають виключно за маршрутизацію HTTP-запитів та повернення відповідей.
  - **Services** - бізнес-логіка розрахунку вартості оренди винесена в окремий сервіс, що робить систему гнучкою до змін (наприклад, зміни відсоткових ставок) та полегшує покриття Unit-тестами.
  - **DTOs** використовуються для інкапсуляції вхідних даних, запобігаючи Over-Posting вразливостям та приховуючи внутрішню структуру БД від клієнта.
- **Документація:** Інтегровано Swagger UI для зручної взаємодії з методами АРІ.

## Запуск проєкту
1. Склонуйте репозиторій:
```
git clone [https://github.com/Derewashchka/BookingAPI.git](https://github.com/Derewashchka/BookingAPI.git)
```

Перейдіть у директорію проєкту:
```
cd BookingAPI
```

Запустіть проєкт (база даних та початкові дані створяться автоматично):
```
dotnet run
```

Відкрийте браузер за адресою https://localhost:<port>/swagger для доступу до документації та тестування ендпоінтів.
